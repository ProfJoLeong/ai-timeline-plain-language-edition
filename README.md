# AI Timeline — Plain-Language Edition

A lay-friendly re-telling of the technical AI Timeline: same research, friendlier words, more pictures. Seventy years of artificial intelligence in six chapters, written for non-technical readers.

**Live site:** https://profjoleong.github.io/ai-timeline-plain-language-edition/

## What it does

A long-scroll interactive timeline covering 73 milestones from 1956 to 2026, with every event explained in plain language:

1. **The Big Picture** — the one-minute summary, followed by "It began with 2 ideas"
2. **The Rule Writers** — early symbolic AI
3. **The Learning Machines** — neural networks learn from data
4. **Learning to Talk** — language models arrive
5. **AI Everywhere** — AI spreads into daily life
6. **The Field Guide** — a 12-lab model zoo with logos, 12 key-person portraits, an honest ledger, and what's next

Throughout: 15 hands-on interactive diagrams (poke the ELIZA chatbot, scrub the diffusion slider, try the neuron and training-loop demos), about 45 acronyms glossed in plain English, worked examples, and light/dark modes.

Research verified live on 27 September 2026; model prices, affiliations, and release statuses shown are that day's facts. Names, prices, and job titles move quickly — check current sources before acting on them.

## How to use it

Open the live site link above in any modern browser — desktop, tablet, or phone. No install, no account, no server. Scroll through the chapters, expand any event for its plain-language story, and try the diagrams as you meet them.

## Technical notes

- Single self-contained HTML file (`index.html`) — HTML, CSS, JavaScript, and images in one file, no build step.
- Images in this GitHub copy are optimized for web delivery (resized/recompressed from the originals); the Muse original is unchanged.
- The only external loads are Google Fonts, which fall back gracefully offline.
- Hosted as a static site on GitHub Pages.
- Portraits are freely licensed (Wikimedia) with credits in the page; company logos in the model zoo are shown for identification under a trademark disclaimer in the page.
